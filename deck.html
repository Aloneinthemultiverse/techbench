The failure

Interruption is two problems. Everyone solves the easy one.

LiveKit stops the audio for free. Almost nobody handles the work that was already running when the user changed their mind.

Unprotected, the agent speaks it and writes it into conversation history — so every later turn is built on a false record of what was said. The user's ears and the model's memory have diverged.

The mechanism

Turn fencing

Every user turn increments a monotonic id. Every async result carries the turn that requested it. One check runs before anything is spoken or committed.

# fence.py
def accept(self, result: Fenced, what: str) -> bool:
    if result.turn_id != self._turn_id:
        self.log.emit("fence_drop", ...)
        return False      # superseded — never spoken, never committed
    return True
  • A new turn also cancels the previous turn's tasks; the fence catches whatever wins the race.
  • The Spoken Ledger records what was actually played when Rime is cut mid-sentence, so the model's memory matches the user's ears.
  • The session keeps accepting audio while Rime is speaking and while tools run — full duplex is a property of the whole application, not of the TTS.

The acceptance test — defined before the demo

Fixed delay, deliberate interruption, one changed constraint

A fixed 3.0s delay is injected into the tool call. The user barges in 3.0s into the agent's turn and revises one part of the request. A run passes only if all five hold:

  • Queued Rime audio stops promptly — measured from the acoustic barge-in to the agent returning to listening.
  • The updated instruction reaches the application — correction handling.
  • No stale tool result is spoken as current — the headline number.
  • Background work is cancelled or reconciled — tasks tagged to the dead turn are cancelled; survivors hit the fence.
  • The final response reflects what the user actually heard — entity tracking against the ledger.

20 trials, split evenly across four interruption types: follow-up, negation, repetition request, topic switch. Reproducible in one second, offline: python eval/run_bargein.py

Honest limits

What this does not prove

  • The live fence sample is n=1. Most interruptions are caught by cancellation before a result reaches the fence. The ablation proves the mechanism; the live drop proves it fires on the real audio path.
  • Time-to-silence is noisy. n=6, raw 544 / 1563 / 3857 / 10446 ms plus two spurious sub-millisecond readings. Median reported; exploratory, not a performance claim.
  • The 20-trial result is logic-level. It drives the real fence objects on a simulated timeline. It proves the invariant; it does not measure acoustic timing.
  • Latency is geography-bound. Rime resolves to AWS us-west-2; from India that is a ~270 ms floor and no APAC endpoint is published.
  • The pipeline fails outright rather than degrading. On an unstable link a DNS failure takes down recognition, the model and Rime at once. Network stability, not model latency, is the binding constraint outside well-connected regions.
  • Telephony is untested and not claimed. Browser-microphone results do not prove telephone performance.
